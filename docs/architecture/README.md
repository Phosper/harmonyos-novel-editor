## 阅读顺序

1. 先看 `feature-ownership.md`：它给出"基础 vs 可选"的结论与代码证据。
2. 再看三份 ADR 的"决策"一节（§2）：那是要你点头的部分。
3. 每份 ADR 末尾都有"本 ADR 不决定"，用来挡住范围膨胀。
