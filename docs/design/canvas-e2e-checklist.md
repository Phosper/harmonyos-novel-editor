# 思路板 · 完整用户流程验收清单（真机）

> 用途：M0–M6 静态完成后，统一走一遍真实使用流程。
> 环境：2in1（MatePad Edge/PC 模式）+ 手机/平板各一遍；debug 包。
> 记录：每步打勾；失败时记「步骤号 + 截图 + hilog 关键字」。

## 0. 构建与安装

```bash
# DevEco 机器，工程根目录
./hvigorw.bat clean --no-daemon
./hvigorw.bat assembleHap --mode module -p product=default -p buildMode=debug --no-daemon
hdc install -r entry-default-signed.hap
```

- [ ] 编译 0 error；如失败，回传 `ArkTS Compiler Error` 的文件:行。
- [ ] 安装后启动，不出现「数据初始化失败」。
- [ ] 旧库升级不崩；hilog 里可出现 `duplicate placements exist` 但不影响启动。

## 1. 建项目 / 进画布

- [ ] 新建项目/书籍，进入文稿列表。
- [ ] 列表头四点菜单 →「思路板」→ 全窗口展开（覆盖侧栏/列表），动画连续。
- [ ] 顶栏右侧「＋ 卡片」「白板」「卡片库」「✕」不被原生三键遮挡。
- [ ] 点 ✕ 收回原布局。

## 2. 建卡

- [ ] 顶栏「＋ 卡片」建写作卡「论文」；落点在视口中心。
- [ ] 卡片库「＋ 新建卡片」建概念卡「建构主义」。
- [ ] 卡片库类型筛选（概念/写作）、排序（最近/标题）生效。
- [ ] 卡片库「复制」生成「建构主义 副本」；「删除」需点两次。

## 3. 编辑器捕获引文（核心）

- [ ] 打开一篇文稿，选中一段文字。
- [ ] 右上出现「选中 N 字 · 加到卡片」；顶部工具条出现「加到卡片」（宽屏）。
- [ ] 点入口 → 选卡面板 → 选「建构主义」→ 提示已加入。
- [ ] 回到画布打开该卡：引文正文、出处（文稿名 · 第 N 段）正确。
- [ ] 点「跳回原文」：同文稿定位到起点；另一篇文稿自动打开、关画布、定位。
- [ ] 跨段选择暂按起点段号记录（已知限制）。

## 4. 素材编辑 / 删除撤销

- [ ] 抽屉里编辑一条引文/判断/笔记，保存后正文变化、出处保留。
- [ ] 删除素材 → 画布/页面底部出现「已删除素材 · 撤销」；5 秒内点撤销恢复。
- [ ] 超 5 秒后撤销条消失，素材不恢复。
- [ ] 多白板共用卡片时，编辑区显示「此卡在 N 块白板使用」。

## 5. 结构：嵌套 / 加章 / 改名 / 菜单

- [ ] 概念卡拖进写作卡：出现「一、建构主义」行，副标题「1 章 · 含 1 张子卡」。
- [ ] 写作卡底部「＋ 添加一章」→ 出现「第 2 章」行，计数 +1。
- [ ] 行尾「✎」改名 → 行标题与卡片标题同步。
- [ ] 卡片长按（触屏）/右键（桌面）→「卡片操作」菜单：打开/重命名/复制/移除/删除。
- [ ] 行右键同样打开菜单。
- [ ] 「从这块白板移除」→ 卡仍在库；底部出现撤销，撤销后回到原位/原子卡链。
- [ ] 「删除卡片」→ 卡从所有白板消失；撤销后卡片、素材、贴放、子卡链恢复。

## 6. 初稿

- [ ] 写作卡「写成初稿」→ 弹窗：章数、包含写作卡素材开关、新建/覆盖/取消。
- [ ] 选「新建一篇」→ 画布收回、打开新稿；每个节点有【待展开】。
- [ ] 写作卡出现「打开初稿」→ 点击回到该稿。
- [ ] 改结构后再生成 →「覆盖当前初稿」→ 旧稿被替换；撤销条恢复旧正文。
- [ ] 勾选「包含写作卡自己的素材」→ 生成稿最前面出现该卡素材。
- [ ] 覆盖后重新打开文稿，格式标题级别仍在。

## 7. 卡片库批量

- [ ] 「选择」→ 勾 3 张 →「放到当前白板」→ 三张错开落下，抽屉最后关闭。
- [ ] 已在当前板的卡显示「已在当前白板」，不能重复放。
- [ ] 行内「从当前白板移除」后，卡仍在库。

## 8. 多设备 / 输入

- [ ] 手机窄屏：抽屉全屏；点「添加素材」键盘弹出，输入框仍在键盘上方。
- [ ] 手机：选中文字浮层不挡选区；选卡面板高度可滚动。
- [ ] 2in1：顶栏/抽屉/选卡面板右侧避开三键；标题区可拖窗。
- [ ] 平板横竖屏切换：画布相机、选中卡不丢；抽屉开合可丢（已知）。

## 9. 持久化 / 备份

- [ ] 杀掉进程重启：卡片、素材、父子、初稿 docId、相机位置保留。
- [ ] 导出备份 → 改动 → 导入恢复：五表、素材、父子、初稿 docId 重指向正常。
- [ ] 恢复后从卡片「跳回原文」「打开初稿」仍可用。

## 10. 失败时回传

```bash
hdc shell hilog | grep -E "Canvas|jscrash|Database init|attachCard|detachCard|dropped duplicate|repointed"
```

- [ ] 截图（步骤号 + 页面）
- [ ] hilog 关键字前后 30 行
- [ ] 是否可复现 / 复现步骤
