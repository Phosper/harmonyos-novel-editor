# 最新版界面第一批整合

本轮承接第一轮可靠性修复，定向迁入用户提供的 `Weaver(4).zip` 中可独立落地的界面能力。保留当前工作区的输入法、长文排版、历史预算、异步文稿归属和上一轮导入/导出/字素修复。

## 本批范围

- 应用显示名与引导文案使用“语流”；工程名、包名、数据库和 JSON 备份的 `app: 'Weaver'` 标识保持兼容。
- 引入同源 `Motion`、`TopActionButton`、`MenuButton` 与图标尺寸令牌，复用现有主题与设备能力判据。按钮具有悬停、按压、焦点、禁用和键盘焦点链处理。
- 文稿列表头提供加号和四点菜单；导入、导出仍走现有 AppShell 业务。宽屏、手机主页与编辑页目录三个宿主均已连接事件。
- 行操作采用 API 26 的 `bindContextMenuWithResponse(MenuElement[])`，统一触摸长按和鼠标右键；彻底删除进入既有确认流程。菜单回调核对项目、条目是否仍存在及废纸篓状态，防止迟到菜单操作其他状态的文稿。
- 正文内使用原生编辑菜单与工具按钮，保留撤销/重做、粗体/斜体/标题、查找、打字机、专注、TXT/Markdown、排版、收藏和灵感动作。宽度不足时折叠为四点菜单，动作仍可达。
- 普通编辑器展示 28vp 文稿标题、归属、字数及原有保存状态；标题重命名复用带项目所有权的对话框。正文列最大 760vp，专注模式最大 720vp。
- 文稿工具集中在内容区，移除窗口标题栏和宽屏应用栏中重复的编辑工具；现有窗口拖动、三键、严格保存后关闭逻辑保留。
- 输入与撤销/重做同步列表摘要、字数和标题，更新已有 `DocItem` 而不重建列表项或改写正文投影。摘要提取读到足够显示的前缀便停止，保留长前导空白后的正文。
- 收藏、恢复和 TXT/Markdown 切换重载列表时重新叠加已打开草稿；打开干净文稿和无变化回调保留原修改时间。
- 设备复验发现按钮通过多参数 Builder 传值后未更新撤销禁用态；改为单对象引用传参，并用显式历史版本通知追加、移除、裁剪与清空。历史预算、输入合并和跨文稿隔离保持既有规则。

这不是完整来包合并：列表/待办段落格式、共享元素转场、FocusWorkspace、头像/昵称、半模态设置与新窗口外壳仍在后续范围。思路板页面和数据层尚未实现，不添加只能点开占位的功能入口。

## 本轮发现但尚未解决的性能问题

- 较早一次长文原生用例虽报告通过，同一时段仍产生 `THREAD_BLOCK_6S`。任务队列记录了超过 6 秒的主线程任务；唯一有效栈在原生 `GetStringIndices` 的数组创建链路，缺少对应 3 秒栈，尚不能确定应用侧或系统侧唯一根因。
- 随后的独立长文重跑及最终整组回归通过，最终故障目录未见新增文件。这不能推翻较早的超时证据，也不能代替长文输入帧率和主线程响应验收；后续应优先专项定位。
- 中途一次测试在 Hypium 开始前因 TestAbility 窗口关闭、`TerminateAbility` 而中止；日志无法确定谁触发关闭，没有 JS 崩溃证据。同包独立重试及最终整组重跑通过。原始异常结果与诊断保留，没有用通过日志覆盖其历史。
