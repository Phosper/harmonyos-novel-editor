# Weaver - 鸿蒙全场景小说创作平台

一款基于 HarmonyOS 的原生小说创作应用，提供从灵感收集、素材管理、人物关系图谱到 AI 辅助写作的全流程创作体验。

## 功能模块

| 模块 | 说明 |
|---|---|
| 📝 编辑器 | 富文本写作编辑 |
| 🎨 素材管理 | 灵感卡片、人物卡片、世界观设定 |
| 🔗 关系图谱 | 人物关系可视化与交互操作 |
| 🤖 AI Agent | 智能辅助写作 |
| ⚙️ 设置 | 主题、偏好设置 |

## 技术栈

- **语言**: ArkTS
- **框架**: HarmonyOS 6.0.2+
- **构建工具**: Hvigor

## 项目结构

```
Weaver/
├── common/              # 公共模块（工具类、组件）
├── features/
│   ├── agent/           # AI 模块
│   ├── editor/          # 编辑器模块
│   ├── material/        # 素材管理模块
│   ├── relationship/    # 关系图谱模块
│   └── settings/        # 设置模块
└── products/default/    # 应用入口
```

## 构建

使用 DevEco Studio 打开项目根目录，同步依赖后即可构建运行。
