# Weaver — 鸿蒙全场景小说创作平台

## 一、创意背景

长篇创作涉及人物、世界观、章节、灵感等多维信息交叉管理，现有工具（Word、纯文本）缺乏结构化组织能力。作者需在多应用间反复切换——正文、人物、关系图——信息碎片化。鸿蒙生态缺少专为长篇小说创作的原生应用。

目标用户：18–30 岁网文/同人创作者，跨设备场景频繁（手机 Idea → 平板大纲 → PC 码字），对深色模式、隐私保护、跨端写作有刚性需求。

## 二、核心功能设计

**双模式**：普通模式（编辑 + 我的）日常写作；专业模式（编辑 + 素材 + 关系 + 我的）覆盖长篇全流程。**响应式三端适配**：基于窗口断点（SM/MD/LG）自动切换底部 Tab、侧边 Tab 或三栏 PC 布局。**关系图**：Canvas 自绘节点，双指缩放、拖拽、连线编辑、按章节高亮。**引导**：3 页 Swiper + 系统托管隐私弹窗，零代码合规。

**架构**：三层 HAR（common→features→entry），7 模块解耦，6 张 SQLite 表，DAO 封装 CRUD。**状态管理**：AppStorage + syncFromVm 兜底。**鸿蒙特性**：一多适配、实况窗（写作计时）、闪控球（跨应用速写）、应用接续、隐私防窥、Agent 半屏。

## 三、市场前景

网文市场超 400 亿元，年增长 10%+，创作用户数千万。鸿蒙设备突破 10 亿，原生创作工具处空白期。免费获取用户，AI Agent 增值服务变现（情节检测、人物分析）。与 Scrivener、纯笔记类形成错位竞争。
